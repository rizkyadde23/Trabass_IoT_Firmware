# T47 — Force Lock/Unlock setelah Logic Level Converter 3,3V → 5V

**Tanggal:** 2026-11-23
**Status:** PASS
**Bike ID:** BK-001
**Transport:** GPRS

## Tujuan
Memverifikasi bahwa tombol Force Unlock dan Force Lock di dashboard admin benar-benar
mengubah kondisi fisik relay/solenoid setelah level shifter dipasang, tanpa mengubah firmware.

## Root cause dan perbaikan
Sebelum T47, GPIO4 ESP32 mengeluarkan HIGH 3,3 V langsung ke `IN` modul relay 5V.
Modul aktif-LOW itu tidak menganggap 3,3 V sebagai HIGH, sehingga relay tetap ON saat LOCK.

Perbaikan:

```text
ESP32 GPIO4 -> LV1 (converter)
ESP32 3V3   -> LV
ESP32 5V    -> HV
ESP32 GND   -> GND (disatukan dengan relay + suplai solenoid)
HV1         -> IN relay
Relay VCC   -> 5V; COM <- + solenoid; NO -> + solenoid; NC kosong
```

Converter bersifat non-inverting. Firmware tidak diubah:
`RELAY_OFF=HIGH`, `RELAY_ON=LOW`, boot default terkunci.

## Langkah uji
1. Pasang logic level converter sesuai wiring di atas.
2. Buka capture Serial COM14 115200 (`T47_serial_capture_20261123.log`).
3. Kirim `POST /api/admin/bike-command` dengan `action=FORCE_UNLOCK`.
4. Amati klik relay, LED hijau, Serial `o`, dan telemetri `lock_state`.
5. Kirim `POST /api/admin/bike-command` dengan `action=FORCE_LOCK`.
6. Ulangi observasi, lalu ambil API/DB dan screenshot dashboard.

## Input

## Keterbatasan
- Pengukuran tegangan tidak dilakukan dengan multimeter. Pembuktian level logika dilakukan
  lewat uji jumper user (`GND`→ON, `3V3`→ON, `5V`→OFF) dan perilaku relay setelah converter.
- Counter `[NET] publish=108 gagal=2` bersifat kumulatif sejak boot; tidak ada event publish
  gagal baru yang teramati selama capture T47.
- Agen tidak dapat membaca isi visual PNG (model tidak menerima input gambar), tetapi file
  screenshot dibuat melalui headless Chrome dan PAGE_INFO memuat URL/detail BK-001.
- status fisik solenoid PASS berdasarkan laporan user setelah perbaikan.

## Kesimpulan
T47 **PASS**. Root cause ketidakcocokan level 3,3 V ESP32 terhadap modul relay 5V terselesaikan
dengan logic level converter non-inverting. Tidak ada perubahan firmware, tidak ada perubahan
pin GPIO4, dan tidak ada perubahan backend/frontend.
